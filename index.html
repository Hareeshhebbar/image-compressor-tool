OptiShrink Deployment & Technical Documentation

1. File Structure & Setup

OptiShrink is engineered as an ultra-fast, zero-dependency HTML5 single-file application requiring zero Node.js server dependencies.

optishrink-website/
├── index.html        # Complete production bundle (HTML, CSS, JS, Routing, Canvas Engine)
├── robots.txt        # Technical SEO web crawler directives
└── sitemap.xml       # XML Search Engine Index Map

2. How to Run Locally

  1. Save the single code block as index.html.
  2. Double-click index.html to open directly in Chrome, Firefox, Safari, or Edge.
  3. Alternatively, run a simple local web server: npx serve or python3 -m http.server 8000.

3. Free Hosting Deployment

GitHub Pages

Push to a GitHub repository, enable Pages in repository settings under main branch root.

Vercel / Netlify

Drag and drop the folder containing index.html into Netlify Drop or import via Vercel Git integration.

Cloudflare Pages

Create a new Pages project and upload the HTML file directly with unlimited bandwidth.

4. Custom Domain & Google Search Console

  • Custom Domain: Add CNAME/A records pointing to your host (e.g. 76.76.21.21 for Vercel).
  • Google Search Console: Add property https://yourdomain.com, verify via HTML tag or DNS TXT record.
  • Sitemap Submission: Submit https://yourdomain.com/sitemap.xml in GSC Sitemaps menu.

5. Compression Algorithm Architecture

OptiShrink implements an iterative binary-search quality reduction algorithm on an HTML5 2D Canvas context:

  1. Loads the source image into an uncompressed Image Object.
  2. Renders onto canvas at initial dimension scales.
  3. Executes binary search across export quality parameters (0.05 to 0.95) using canvas.toBlob().
  4. If target size is ultra-small (e.g. 20 KB) and quality reaches minimum threshold (0.2), the algorithm proportionally downscales canvas width/height by 15% and re-runs quality checks until exact target byte budget is met.
